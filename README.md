# Phyton

This repository contains a simple Pong clone implemented in Python using [Pygame](https://www.pygame.org/).

## Running the game

1. Install dependencies:
   ```bash
   pip install pygame
   ```
2. Run the game:
   ```bash
   python pong.py
   ```

Use `W`/`S` to move the left paddle and the arrow keys to move the right paddle.
